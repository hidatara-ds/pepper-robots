If you have been explicitly authorized to contribute to this project:

1. **Sign Confidentiality Agreement**: All contributors must sign a Non-Disclosure Agreement (NDA)
2. **Copyright Assignment**: All contributions become the property of the copyright holder
3. **Follow Code Standards**: Adhere to the established coding standards and practices
4. **Documentation**: All code must be properly documented
5. **Testing**: All contributions must include appropriate tests
6. **Review Process**: All changes must be reviewed and approved by the copyright holder

## Reporting Security Issues

If you discover a security vulnerability:

1. **DO NOT** create a public issue
2. **DO NOT** disclose the vulnerability publicly
3. Contact the copyright holder directly through secure channels
4. Provide detailed information about the vulnerability
5. Allow reasonable time for the issue to be addressed
